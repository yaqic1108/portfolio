# Mechanical Engineering Portfolio

A simple static portfolio built with HTML, CSS, and JavaScript.

## Customize first

1. Replace `YOUR NAME` with your name.
2. Replace `your.email@example.com` with your email.
3. Add your LinkedIn URL.
4. Put your resume in this folder as `resume.pdf`.
5. Replace the placeholder project images with your actual CAD/prototype photos.
6. Update the Hunter Roberts and New Line Structures details.
7. Replace Project Three with your strongest remaining project.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all files and folders from this project.
3. In GitHub, open Settings → Pages.
4. Select deployment from the `main` branch.
5. Your site will be available at `https://yourusername.github.io/`.

For a custom domain, purchase a domain separately and configure it through GitHub Pages.
